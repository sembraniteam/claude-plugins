# Revision Triggers

Shared trigger table for `design/SKILL.md` Step 9 (first-time design confirmation loop) and
`review/SKILL.md` steps 4a–4b (revision scope gathering and diagram update). Both skills consult this table when
deciding what else must be re-run once a specific piece of the design changes — it is the single source for the mapping,
so a new trigger or a changed target only needs to be added here once.

`review/SKILL.md` is an **authorized second writer** of every `session.json` key below except `description` and
`domainModel`'s first pass (`design/SKILL.md` writes those first) — see `session-schema.md` section "Single writer per
key". Where the table says "overwrite in full", this applies equally to `design/SKILL.md` Step 9 revising its own
first-time answer and to `review/SKILL.md` revising a prior pass's answer — never merge with the previous value.
